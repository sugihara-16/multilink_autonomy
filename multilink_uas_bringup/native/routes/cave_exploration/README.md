# 洞窟走査用の固定軌道

UASの `darpa_cave_01.sdf` の衝突用メッシュから生成した、DRAGON固定四角形構成向けの往復経路。
三叉路、東側の直角の曲がり角、北側通路、南側の幅が変わる通路と折れ曲がりを通る。
総延長596.318 m（帰路を含む）、50通過点、世界座標の高さ2.0–5.5 m。
全洞窟の網羅ではない。地形の真値は経路作成にだけ使い、LIO/VIOには入力しない。

- `overview.png`: 経路の俯瞰図と高さ。灰色は、ボクセル上で余裕を確保できる領域を上から投影したもの。
- `waypoints.csv`: 世界座標の位置。基準点はDRAGONの `fc`（IMU位置）。
- `trajectory.csv`: 時刻・位置・yaw・速度・yaw角速度・加速度。通常0.5秒刻み、各区間端の前後では短くなる。
- `segments.json`: 連続軌道の定義。区間内で `u=(t-t0)/duration`, `s=10u^3-15u^4+6u^5` とし、始点と終点の間を `s` で補間する。位置とyawに同じ式を使う。
- `route.json`: 長さ、速度条件、検査結果、通過区画。
- `mesh_sources.json` / `robot_envelope.json`: 使用形状・ハッシュ値・機体の寸法検査。

## 動き

始点・終点は世界座標 `(40,5,2)` m。飛行制御のCoG位置ではなくFC位置である。
離陸後に始点へ移る区間と着陸は含まない。yawは開始時0 rad、進む方向へ停止旋回してから移動する。
曲がり角では速度・加速度がともに0になる5次式を使い、検査済みの直線区間から外れない。
最高速度0.8 m/s、最高加速度0.4 m/s²、最大yaw角速度0.3 rad/s、所要時間26.750分。
各折れ点で停止する保守的な評価用軌道であり、滑らかに曲がり続ける飛行ではない。
軌道の時刻は試験開始からの相対時間。`world` はGazeboの世界座標であり、推定器の原点とは別。
CSVへ無制約の曲線補間を適用すると検査範囲外へ出るので、上記の連続軌道を使う。

## 衝突の確認

1. SDFの配置・回転、COLLADAの単位（cm→m）、各メッシュのscaleを適用。
2. 壁・床・天井を0.5 mのボクセルにし、空間のつながりを探索。地上から天井の間に限定する。
3. 機体中心と表面の距離がボクセル上で1.95 m以上の場所を結び、直線で短縮。
4. 最後に元の衝突用三角形メッシュと経路を直接照合。経路を0.1 m以下の間隔で検査し、検査点の間も覆うため最小距離から0.05 mを引く。無限の地面z=0も検査。

全連続経路で中心から環境表面まで1.95 m以上。現在の四角形・ジンバル0の機体は、
可視形状と衝突形状の全頂点がFCから半径0.725303 m以内。半径1.0 mの球で機体を包んでも
環境まで0.95 m以上残る。回転してもこの球の範囲は変わらない。
この値は形状上の余裕であり、飛行中の追従誤差を測った結果ではない。
任意の関節変形やジンバル動作、動的障害物、離陸・着陸は未検証。
Gazebo上の経路追従飛行、推定器の評価はまだ行っていない。

## 再生成

仮想環境は不要。オフライン用依存は `native/requirements-route.txt`。
ROSの環境はURDF内のpackage参照を解決するためだけに使う。

```bash
source /root/ros2/aerial_robot_base_ws/install/setup.bash
python3 /root/uas_native/plan_cave_route.py \
  --output /root/uas_native/logs/cave_route_rebuild
python3 /root/uas_native/export_cave_route.py \
  --input /root/uas_native/logs/cave_route_rebuild \
  --output /root/uas_native/routes/cave_exploration \
  --urdf /root/uas_native/logs/20261001-133612-302229/dragon_slam.urdf
```

上記URDFは今回の検査入力。ログを削除した場合は現在のDRAGON設定から同じ固定四角形URDFを生成して指定する。
ボクセル・距離配列は `logs` のみに保存し、成果物には含めない。
探索領域は世界座標 `[15,-245,-5]`–`[205,65,50]` m、経由区画は生成スクリプトに定義。
今回の固定洞窟向けのツールであり、任意SDFの入れ子モデルや別の地面配置を自動解釈する汎用プランナーではない。
