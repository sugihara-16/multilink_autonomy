# 単眼LIVO 4条件比較：結果

今回の設定・2例ではFAST-LIVO2が位置・姿勢の両方で最小のRMSEでした。

- **MIMOSA OFF / ON**：標準閾値trans=40、rot=0では退化判定0回。軌跡は完全一致しました。ON分岐自体は修正後の別の強制発火試験で439回作動、158姿勢の有限性を確認。今回の結果は「この閾値では検出できない」ことを示し、閾値調整後の方式の上限精度を示しません。
- **FAST-LIVO2**：run2a_endで位置RMSE 0.0204m、run1_tail_a2_prefixで0.3478m。長い方の姿勢RMSEは4.12°、最大7.86°であり姿勢誤差は残ります。
- **MIMOSA + DRPM**：短い方の位置RMSEは12.56→4.63mへ改善。しかし姿勢RMSEは1.49→5.23°へ悪化。長い方は位置4.88→9.76m、姿勢76.11→123.00°へ悪化し、今回の移植・設定では姿勢発散を解決できませんでした。
- 参考の単眼ROVIO単独は、位置RMSEが約1.13m / 4.89m、姿勢RMSEが約0.045° / 0.061°。MIMOSAへ融合すれば単独VIOより必ず良くなる結果ではありません。

## 入力・評価・検証
- link3カメラ1台、同じIMUとLiDAR、同じ校正、同じ追従区間。カメラ選定根拠はcamera_selection.json。特徴数平均はlink1/3/4で188.8/363.2/295.8、画像内分布の指標は0.662/0.800/0.696。
- 評価区間：run2a_end 63.66–113.14秒（49.48秒）、run1_tail_a2_prefix 63.78–263.96秒（200.18秒）。離陸・ホバリング・方向合わせは初期化にのみ使用。
- 各方式・各飛行の開始時に1回だけ位置・姿勢を真値へ整合。全軌道フィッティング、スケール補正、途中の再整合なし。
- 真値位置の線形補間と姿勢の球面補間。元の整数nsを保持し、外挿なし。誤差図は世界XYZと真値機体に対する相対回転のRoll/Pitch/Yaw。姿勢の総合RMSEは3軸の単純和ではなく回転角の大きさで計算。
- 全8ケース正常終了。追従中の出力は各方式989点 / 4004点、20Hz、最大間隔0.05秒。元画像時刻との照合で欠落0、余計な時刻0。LiDAR待ちによる破棄・ROVIO共分散閾値による破棄0。
- MIMOSAは同じ時刻のセンサー更新後の最終状態を記録。元の重複行は保持し、評価時には同じ時刻の最後の更新を使う。
- DRPMの合成試験：正常3次元形状の6方向を維持、雑音付き平面の3方向を抑制、結果は有限・半正定値。非退化確率は公式ソースと1e-12以内で一致。GTSAMの数学ライブラリを読み込んだ状態でも検証。

## 解釈の範囲
同じセンサーを使う設定比較です。MIMOSAは既存のIMU・odometry因子の重み（並進0.1m、回転2°）を3条件で共通に保持し、FAST-LIVO2はセンサー接続・幾何設定以外は公開設定を基準にしています。両者の内部の重みを同じ数値にした比較ではありません。DRPMは下記の情報量の重み付けによる移植で、論文の独立ICPの再現ではありません。

今回の姿勢発散について、融合の重み、IMU雑音設定、地図に蓄積する面法線の不確かさ、DRPMのグラフへの適用方法のどれが支配的かは切り分けていません。したがって、この2例から「DRPM一般が劣る」とは結論しません。次にMIMOSAを改善する場合は、これらの信頼度設定と姿勢・重力の整合を先に確認する必要があります。

4条件の表はそれぞれ1回の完成試行です。FAST-LIVO2は並列計算を含み、試行間の完全な数値一致までは保証していません。最終表には同じ順序で実施した完成キャンペーンの値だけを載せています。
